# Axl's Animal Adventure

A game made for Axl. Rescue lost baby animals across 30 landscapes, learn maths, reading and nature along the way, and build them a home on Sanctuary Island where they grow up.

## Play
Open the game's GitHub Pages address (Settings → Pages shows it).

**Full screen on a tablet or phone:**
- **iPad / iPhone:** open the link in Safari → Share → **Add to Home Screen**, then open it from the new icon.
- **Android:** open the link in Chrome → ⋮ menu → **Install app**.

It works offline once opened. Saves stay on the device; use **💾 Backup** on the main menu to move a save between devices.

## What's here
- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` — the installable game that GitHub Pages serves.
- `source/` — the source files, the build script and the changelog.
